# DataAnalyst_Project

## 📌 Project Overview

This project focuses on **Data Processing and Analysis** using multiple data analytics tools — **Excel, SQL, Python, and Power BI**.

The main objective of this project is to clean, process, analyze, and visualize employee data to generate meaningful insights and demonstrate practical data analyst skills.

---

## 🎯 Objectives

* Clean and organize raw employee data
* Identify and remove duplicate records
* Sort and filter employee information
* Perform data analysis using SQL
* Analyze data using Python
* Create interactive visualizations and dashboards using Power BI
* Present insights in a clear and understandable format

---

## 🛠️ Tools & Technologies

* **Excel / Google Sheets** – Data cleaning, sorting, filtering, formatting
* **SQL** – Data querying, aggregation, filtering, and analysis
* **Python** – Data analysis and processing
* **Power BI** – Data visualization and dashboard creation

## 🔍 Key Insights

Some of the key insights obtained from the analysis include:

* Employees are distributed across multiple departments such as HR, IT, and Sales.
* IT employees have comparatively higher salaries in the given dataset.
* The dataset contained a duplicate employee record, which was identified and removed during data cleaning.
* Salary and joining year can be analyzed to understand employee patterns and workforce distribution.
